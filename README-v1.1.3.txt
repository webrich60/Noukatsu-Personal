やさしい脳活日和 個人版 v1.1.3（12ゲーム履歴転記 修正）

■ 修正内容
・元の12種類のゲーム結果を、終了時に個人版の履歴へ直接送信します。
・ゲーム結果を一時保存し、受け取りが途切れた場合でも再取込できるようにします。
・同じ結果の重複取り込みを防止します。
・ゲーム終了画面に「履歴に保存しました」の確認表示を追加しました。
・設定画面に「🧠 ゲーム結果を再取込」ボタンを追加しました。
・ゲーム中のGAS同期処理が重なっても、未送信結果を後続処理で取り込めるようにしました。
・ゲームの問題・得点計算・12種類の画像・フィジカル4種目・GAS連携設定を維持しています。
・ゲーム側のService Workerを更新し、古いゲームページのキャッシュが残りにくいようにしました。

■ 導入手順
1. ZIPを解凍して、GitHub「Noukatsu-Personal」に中身を【フォルダ構造を維持して】上書きアップロードします。
2. games/index.html と games/sw.js、ルートの index.html、app.js、bridge.js、sw.js を必ず更新してください。
3. GitHub Pagesの公開URLを開き、v1.1.3 と表示されることを確認してください。
4. 12種類のゲームから1つを最後までプレイします。終了画面に「✓ 個人版の履歴に保存しました」が出るか確認します。
5. 個人版の「履歴」画面にそのゲーム結果が1件追加されたか確認します。
6. 「設定」→「未確認の記録を転記・照合」を押し、Googleスプレッドシート「脳活履歴」で区分「game」を確認します。

■ GASについて
GASのdoPostはすでに source='game' と source='physical' の両方を受け付けるため、今回のGASコード更新・再デプロイは不要です。

■ 以前の履歴
v1.1.2以前で端末に保存されているゲーム記録は、そのまま残して再転記対象にできます。
ただし、端末にも記録されていなかった過去のゲーム結果は、あとから正確に復元できません。

■ 注意
このアプリは個人利用版ですが、GitHub Pagesは公開閲覧可能です。同期トークンをGitHubファイルに埋め込まないでください。
ブラウザのサイトデータは削除しないでください。既存の記録と設定が消える可能性があります。
キャッシュやGitHub Pagesの反映タイミングで古い画面になる場合は、PCでCtrl+Shift+Rを使用してください。
