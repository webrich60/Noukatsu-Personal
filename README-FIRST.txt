やさしい脳活日和・個人専用統合版 v1.0.0 （2026-10-28）
=================================================
このZIPは、ユーザー提供「脳活アプリテスト版.zip」（12ゲーム v1.6.6）を正本とし、
本日の個人版フィジカル脳活（4種目）・ストップウォッチ・履歴・GAS同期を統合したものです。

■ GitHub Pages に公開する方法
1. 新規リポジトリ名の例：Noukatsu-Personal
2. このZIPをPCで解凍する。
3. 解凍したフォルダーの中身（index.html, app.js, style.css, bridge.js,
   manifest.webmanifest, sw.js, games/ など）を GitHub リポジトリのルートへアップロード。
   ZIP自体をアップロードしてもサイトになりません。
4. リポジトリの Settings > Pages で main ブランチ / root を選択して公開。
5. ブラウザで公開URL /Noukatsu-Personal/ を開く。
※既存の一般公開・販売用ゲームのリポジトリは変更しないでください。
※このZIPには GAS コードを含めていません。GASは別配布のCode.gsを使用。

■ 運用
ホーム→ゲーム＝元12ゲームそのまま表示。終了後に履歴へ成績記録。
ホーム→からだ脳活＝片足立ち・椅子立ち上がり・２分間足踏み・座位足踏み＋暗算。
難易度：初心者／中級者／上級者。片足立ちは左右と開眼/閉眼を記録。
３秒準備後ストップウォッチ開始、手動終了、回数＋１／−１／数値入力。
データは端末のブラウザ内に保存。必要に応じCSV/JSONでバックアップ可能。

■ GASの準備（別ファイル Code.gs）
1. 空のGoogleスプレッドシートを作成し「拡張機能」→「Apps Script」。
2. 別配布の Code.gs を貼り付けて setupOnce() を実行。
3. 実行ログの SYNC_TOKEN（秘密）を控える。
4. デプロイ＞新しいデプロイ＞ウェブアプリ。
   実行者「自分」、アクセス「全員」（GAS側のトークン照合で書き込み制限）。
5. 個人版の設定画面で /exec URL とトークンを入力して保存する。
6. 「未確認の記録を転記・照合」を押し、シート保存確認済みを確認。
以後、オンライン時に自動送信し、未確認分は起動時と手動で再試行。
注：接続環境がない場合、シート連携は未テスト。端末への保存は有効。

■ 安全とデータ
本アプリは医療診断や脳年齢の判定ツールではありません。
開眼・閉眼、補助の有無、時間が異なる結果を年齢判定に流用しないでください。
閉眼片足立ちは転倒の危険があり、介助者の同席が必要です。
腰痛などがある場合は医療者に確認してください。
「個人版」という名称でもGitHub Pagesの公開URLは原則他人も閲覧できます。
履歴やトークンをGitHubリポジトリのファイルに書き込まないでください。
端末を変えるとスマホ内の履歴は自動復元されないので、JSONバックアップも使用します。
