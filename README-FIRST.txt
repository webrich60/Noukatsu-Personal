やさしい脳活日和｜個人専用 v1.1.2
=================================
更新日：2026-10-28

■ このアプリについて
無料の元「やさしい脳活日和」（ユーザー提供ZIPのv1.6.6・全12ゲーム）を一切置き換えず、
個人用として独立したアプリへ取り込みました。販売、サブスク、広告、会員登録はありません。
画面はオリジナルのフクロウを中心に、フィジカル４種目の人物も漫画風のイラストに統一。
ログインなしで使えるシングルユーザー版です。

■ GitHub Pages にアップロード
Noukatsu-Personal-v1.1.2-Cache-Storage-Fix-GitHub.zip を解凍し、ZIP内の「中身」を
新規リポジトリ Noukatsu-Personal のルートにアップロードしてください。
index.html, app.js, style.css, bridge.js, sw.js, manifest.webmanifest, games/ が必要です。
Settings > Pages > Deploy from a branch > main / (root) でサイト公開。
※ 元の誰でも使えるアプリのGitHubリポジトリにはアップロードしません。
※ 「個人版」でもGitHub PagesのURL自体は原則公開されます。ログインによる閲覧制限はありません。
※ GASの同期トークン、個人の記録、個人情報をGitHubへアップロードしないでください。

■ 使い方
ホーム：元の12ゲーム + ４つの身体脳活。
フィジカル：片足立ち、椅子立ち上がり、２分足踏み、座位足踏み＋暗算。
それぞれ初心者／中級者／上級者を選択、タイマー・回数・正答数を記録。
片足立ちの目を閉じるモードは上級者かつ介助者の同席が必要です。
ゲーム結果と身体脳活の結果は、スマホのブラウザに記録されます。
結果画面・履歴に同じ条件での記録を表示します。
「設定」でGAS URLと同期トークンを登録すると、記録後にスプレッドシートへ送信します。
ネット接続失敗時は端末の未確認履歴から再試行します。

■ GASのセットアップ（別ファイル: Noukatsu-Personal-Code-v1.1.0.gs）
1. 自分のGoogleスプレッドシートを開き「拡張機能」→「Apps Script」。
2. Code.gs の内容を貼り付けて保存。
3. 関数 setupOnce() を一度実行し、実行ログの SYNC_TOKEN を控える。
4. 「デプロイ」>「新しいデプロイ」>「ウェブアプリ」。実行者「自分」。
   現行コードは実行URLに外部からPOSTする仕様なので、アクセス「全員」が必要です。
   トークンは秘密にし、ソースコードに記載しないこと。
5. /exec で終わるデプロイURLと SYNC_TOKEN を個人版の「設定」に入力。
6. 「未確認の記録を転記・照合」で保存確認。
   インターネットとGAS実行権限が必要です。実際のGoogle側への接続テストは未実施。
※ 以前のv1.0.0でGAS設定済みなら原則として同じURLとトークンが使えます。
※ すでに存在する履歴を消さず、同じブラウザの保存データを引き継ぎます。

■ 安全・科学的根拠
これは娯楽・運動記録用で、診断・認知症判定・正確な脳年齢の推定を行いません。
片足立ちの年代別平均値：Springer et al. (2007), PMID 19839175
https://pubmed.ncbi.nlm.nih.gov/19839175/
https://www.sralab.org/rehabilitation-measures/single-leg-stance-or-one-legged-stance-test
30秒椅子立ち上がり：CDC STEADI 30-second Chair Stand
https://www.cdc.gov/steadi/media/pdfs/steadi-assessment-30sec-508.pdf
補助の有無、計測上限、閉眼、試行回数が違う測定では研究平均と直接比較できません。
痛み・ふらつきがあれば止めてください。閉眼片足立ちは一人で行わないでください。

■ 個人データ
端末内：localStorage と IndexedDB（代替保存）。ブラウザデータ消去や端末変更で端末内履歴が消えることがあります。
「設定」→「JSONを保存」で定期的にバックアップしてください。
スマホ/PCをまたぐリアルタイム双方向同期や履歴の自動復元は未実装です。
